## Introduction
> An operating system is **software** that **manages** a computer’s hardware. {% fn %}

Operating System provides environment to run application program and acts as an intermediary
between the computer user and the computer hardware. Before the era of operating system and software, 
programming (activity to create a program) is done directly to the hardware. The resulting “program” 
is in the form of hardware and is termed a **hardwired program**{% fn %}.

{% include post-image.html image="hardwired.png" caption="programming in hardware" label="img1" %}

In this system, there is a small set of basic logic components that can be combined in various ways 
to store binary data and perform arithmetic and logical operations on that data.
If there is a particular computation to be performed, a configuration of logic components 
designed specifically for that computation could be constructed. 
We can think of the process of connecting the various components in the desired configuration 
as a form of programming.

It means, this system can only do one specific task at one time and to create another "program" for
doing different task, we have to do "programming in hardware" again, i.e. connecting the various components 
in the desired configuration.
